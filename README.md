# Neomarket (монорепозиторий)

Два микросервиса в отдельных папках:

| Папка | Назначение |
|--------|------------|
| `marketplace/` | B2C витрина (Django), прокси к B2B |
| `b2b/` | B2B каталог и API продавца (Django) |

Запуск и переменные окружения — в README внутри каждой папки (при необходимости добавьте сами).
